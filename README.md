# Particle Keyboard - البناء السحابي عبر GitHub Codespaces

كل الخطوات هون من المتصفح بس، ما بتحتاج تنزّل ولا برنامج على لابتوبك.

## 1. اعمل حساب GitHub (لو ما عندك)
روح لـ github.com واعمل حساب مجاني.

## 2. أنشئ Repository جديد
- بصفحة GitHub الرئيسية اضغط "+" فوق يمين ← New repository
- اسمه: `ParticleKeyboard`
- خليه **Public** أو **Private** (الاثنين منيح)
- اضغط Create repository (بدون إضافة أي ملفات جاهزة)

## 3. ارفع ملفات المشروع
- بصفحة الـ repository الفاضي، بيطلعلك خيار "uploading an existing file" — دوس عليه
- فك ضغط ملف `ParticleKeyboardCloud.zip` يلي بعتلك ياه على أي مجلد بلابتوبك
- اسحب **كل الملفات والمجلدات** (بما فيها المجلد المخفي `.devcontainer`) وأفلتها بصفحة الرفع
- تحت اكتب أي رسالة (مثلاً "أول رفعة") واضغط Commit changes

⚠️ **مهم**: تأكد المجلد `.devcontainer` انرفع، لأنه هو المسؤول عن تجهيز البيئة تلقائياً. لو GitHub ما قبل رفع مجلد مخفي بالسحب والإفلات، جرب ترفعه من خلال الضغط "Add file" ← "Upload files" واختيار الملفات يدوياً (مش سحب وإفلات).

## 4. افتح Codespace
- بصفحة الـ repository، اضغط الزر الأخضر **Code**
- تبويب **Codespaces** ← **Create codespace on main**
- استنى 2-5 دقايق أول مرة (عم يبني بيئة كاملة فيها Java وAndroid SDK)

## 5. ابني المشروع
لما يفتح المحرر (شكله متل VS Code)، افتح Terminal من تحت (أو من القائمة Terminal ← New Terminal) واكتب:

```
gradle assembleDebug
```

استنى لحد ما يخلص (أول مرة بياخد كم دقيقة). إذا انتهى بدون أخطاء حمراء، معناته نجح البناء.

## 6. حمّل ملف APK
- من مستكشف الملفات على اليسار، افتح المسار:
  `app/build/outputs/apk/debug/app-debug.apk`
- دوس كبسة يمين على الملف ← **Download**

## 7. ثبّته عموبايلك
- انقل الملف لموبايلك (تيليجرام لنفسك، Google Drive، بريد إلكتروني...)
- افتحه من الموبايل عشان يثبت — إذا طلب منك تفعيل "تثبيت من مصادر غير معروفة"، وافق (هاد طبيعي لأي APK خارج المتجر)

## 8. فعّل الكيبورد
- إعدادات الموبايل ← اللغة والإدخال (Language & Input) ← لوحات المفاتيح على الشاشة ← إدارة لوحات المفاتيح
- فعّل **Particle Keyboard**
- افتح أي تطبيق فيه صندوق كتابة، اضغط مطولاً على أيقونة تبديل الكيبورد، واختار Particle Keyboard

## لو صار خطأ بالبناء
انسخلي نص الخطأ الأحمر يلي بيطلع بالـ Terminal وابعتهولي، بصلحه معك.

## ملاحظة عن الحد المجاني
Codespaces عندها ساعات مجانية شهرياً كافية جداً لمشروع بحجمنا (ما بنحتاج محاكي، عم نختبر مباشرة عموبايلك الحقيقي). إذا خلصت الساعات المجانية بشهر معين، بتقدر تنشئ حساب GitHub تاني أو تستنى الشهر الجاي.
